Gloam 0.2.1 fixes pointer interaction and Firefox visibility in the live desktop.

- Draw software cursors in the spatial renderer and enable them for the live
  greeter and desktop to avoid virtual GPU cursor-plane orientation and hotspot
  issues. Include an Adwaita cursor theme and initialize the default pointer.
- Keep spatial misses from reaching invisible flat window rectangles, and give
  shell overlays priority over window titlebars when clicking.
- Deliver ordinary right clicks to applications. Use Alt+right-drag to orbit
  the camera.
- Open Firefox on the current workspace and preserve the session environment
  when launching applications. Enable Firefox's native Wayland backend.

Validation: compositor and shell builds, 11 unit tests, headless shell and
Wayland protocol tests, transformed-layer tests, and a GLES2 pointer regression
test covering cursor orientation, hotspots, click coordinates and overlay
priority. Firefox 157 was verified to open and focus on the current workspace
with Afterglow rules. The rebuilt ISO has not yet been manually tested in QEMU.
